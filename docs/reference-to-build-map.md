## 页面映射

### Visual Atlas 首页 / 展览式档案入口

交互假设：页面保留一张全幅主视觉作为展览入口，同时增加 3 张可独立点击、替换和响应式重排的案例卡。右侧档案条目、分类链接和主 CTA 也保持可交互；卡片不是装饰拼贴，而是产品真实案例的入口。

总判断：需要 1 个主视觉素材和 3 个独立案例卡素材；第一版优先整理现有案例图片，不把卡片合并成一张拼贴图。

## 素材来源与风险

### 优先使用已有真实素材

- 产品仓库已有的案例图应作为真实案例图片来源，不重新生成已有事实内容。
- 现有产品截图只用于理解当前产品，不作为最终网页背景直接裁切使用。
- `By Aing / Layers` 是确认过的作者品牌，不生成头像或虚构个人资料。

### 需要生成或整理的素材

- `va-hero-image`：需要按第三个方向重新生成一张不带网页 UI 文字的电影感主视觉。
- 案例缩略图：优先从现有 `data/images/` 案例资源中整理，保持真实案例与分类对应。

### 不得烙进图片的内容

- Visual Atlas 品牌名称
- 导航文字
- CTA
- 案例编号、分类和任何未来需要维护的事实信息
- Aing / Layers 作者链接

## 歧义分叉：主视觉的装饰性图像组合

推荐默认方案：保留一张完整主图作为展览入口，另外增加 3 个独立案例卡媒体槽位。主图负责品牌氛围，案例卡负责“图鉴”的可探索性；卡片图片、标题、编号和分类彼此分离，保持可编辑和可替换。

备选方案：把 3 张案例卡作为主图周围的静态装饰拼贴，只保留一张合并素材。这个方案更艺术，但会牺牲案例点击、替换和真实内容维护能力，因此不推荐。
